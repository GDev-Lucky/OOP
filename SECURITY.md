# Security Policy

## Supported versions

OOP is pre-release software. Only the latest source on the default branch is considered for security fixes.

## Reporting a vulnerability

Please do not publish a public issue for a suspected vulnerability. Use GitHub's private vulnerability-reporting feature for this repository when it is available.

If private reporting is not enabled, wait for a private reporting channel to be published rather than disclosing exploit details in a public issue. This repository does not currently publish a separate security contact.
